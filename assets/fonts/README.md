# Fonts

Figtree (body) and Outfit (headings), weights 400, 500, and 600, are served locally so the homepage does not depend on a third-party font request.

Source: Google Fonts, https://fonts.google.com/specimen/Figtree and https://fonts.google.com/specimen/Outfit.

Both families use the SIL Open Font License. See the included `OFL-figtree.txt` and `OFL-outfit.txt` files.
